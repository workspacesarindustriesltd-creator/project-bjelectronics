# BJ Electronics Platform

Production-oriented e-commerce platform with independently built customer and administrator applications, a modular Express API, MySQL persistence, Redis-compatible distributed caching, and Cloudinary media delivery.

## Structure

```text
apps/
  store/                 Customer storefront entry
  admin/                 Protected operations portal entry
server/
  http/                  Express composition, validation, error handling
  modules/               Auth, catalog, orders, account, admin routes
  services/              Redis cache and Cloudinary signed media services
  repository.js          Transactional MySQL persistence
  auth.js                Customer/admin session boundaries
src/admin/                Cloudinary administrator media workflow
database/
  schema.sql             Canonical schema
  migrations/            Ordered production migrations
  seeds/                 Optional seed SQL
scripts/
  migrate.mjs            Idempotent migration runner
  *-boundary-plugin.mjs  Store/admin production bundle isolation
worker/                   Store/admin application routing
```

## Local development

1. Copy `.env.example` to `.env` and configure MySQL plus administrator credentials.
2. Optionally add Upstash Redis REST and Cloudinary credentials.
3. Run `npm ci`.
4. Run `npm run db:migrate`.
5. Run `npm run dev:full`.

Services:

- Storefront: `http://localhost:5173`
- Administrator portal: `http://localhost:5174/admin/login`
- API: `http://localhost:4000/api/health`

## Production validation

```bash
npm ci
npm run check
npm run security:audit
```

The production checks build both frontends, prepare the self-contained Hostinger `dist` runtime, verify administrator/storefront bundle boundaries, run API and integration tests, and audit runtime dependencies.

## Redis cache

Hostinger Business and Cloud web hosting do not expose a local Redis server. Production uses an external Redis-compatible HTTPS REST cache. Catalog requests are cached with cache-aside behavior and automatically fall back to MySQL if Redis is unavailable.

## Cloudinary media

The administrator **Media** workspace supports signed image and video uploads. Upload signatures are generated by the protected Express API, the API secret remains server-side, and product images use Cloudinary automatic format and quality optimization.

See [`INTEGRATIONS_HOSTINGER.md`](./INTEGRATIONS_HOSTINGER.md) for account setup, environment variables, automatic GitHub deployment, verification, and failure behavior.

## Checkout

The platform intentionally contains no external online payment gateway. Supported order methods are cash on delivery and bank transfer. Inventory is committed atomically when the order is placed and restored when an order is cancelled.
